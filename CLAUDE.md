# Atrium

Chrome extension (Manifest V3) that replaces the new tab page with one built from your bookmarks.

## Git

This section overrides the branch rules in the global `CLAUDE.md` for this project.

* Work directly on `main`. Do not create feature, fix or other branches.
* Commit straight to `main` when a piece of work is done and its checks pass.
* The repo has no remote, so there is nothing to push and no pull requests to open.
